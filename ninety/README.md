# NINETY

A reverse marketplace for second-hand car parts, with an enforced clock and its
own logistics.

A buyer posts the part they need. The request fans out to every relevant
scrapyard terminal at once. Suppliers have **15 minutes** to respond with stock,
photos and price, or they drop out of the job. The platform strips supplier
identity, returns anonymous offers within **30 minutes**, takes payment, and
dispatches a courier to deliver in **90 minutes**.

Neither side ever sees the other. That is not a privacy feature — it is the
business model.

> Working codename. Replace after trademark clearance in the UAE and South Africa.

## Get it running

**Prerequisites:** Node 20+, pnpm 9+, Docker.

```bash
cp .env.example .env          # then fill in JWT_SECRET and JWT_REFRESH_SECRET
docker compose -f infra/docker-compose.yml up -d
pnpm install && pnpm bootstrap   # ← the one command: migrate + seed
pnpm dev
```

`pnpm bootstrap` runs migrations from empty and seeds both markets. The API then
answers on `http://localhost:3000`.

Verify PostGIS before anything else. If this does not return a version, stop and
fix it — every geo query in the product depends on it, and discovering its
absence in the matching engine is expensive:

```bash
docker compose -f infra/docker-compose.yml exec db \
  psql -U ninety -d ninety -c "SELECT postgis_version();"
```

**No Docker daemon?** `./infra/dev-services.sh` brings up the same PostGIS
database and Redis directly. It is a convenience for sandboxes and CI runners,
not the supported path.

Confirm everything is up:

```bash
curl -s localhost:3000/v1/health | jq
```

## The rules that outlive every other decision

These are enforced mechanically, because none of them survives being a
convention that reviewers are asked to remember.

**1. No market-specific value may appear as a literal in application code.**
Not a currency symbol, a tax rate, a commission percentage, an SLA number, a
locale string, a timezone, a city or a country name. Everything comes from the
`markets` table through `MarketConfigService`.

`packages/config` scans all application source and fails the build on a
violation. Watch it bite:

```bash
./scripts/guard-demo.sh
```

This is the difference between adding the second country in a week and adding it
in two months.

**2. Arabic is a launch requirement, not a later addition.** Every
system-generated string is looked up by key against the caller's locale. A key
present in English and missing in Arabic fails the build:

```bash
./scripts/locale-demo.sh
```

RTL is layout, not translation. It is built into the first screen of both
front-ends rather than retrofitted.

**3. Money is integer minor units. Never floats** — not in the database, the
API, or the client. There is one rounding policy, applied in one place. The
`orders` table enforces reconciliation as a database constraint, not only as a
test.

**4. Every deadline is an absolute UTC timestamp generated by the server.**
Clients render countdowns by subtracting from their own clock. A yard's tablet
with a wrong system clock must not be able to argue about the 15 minutes.

**5. Timers are delayed jobs, never a cron sweep.** A sweep passes every
functional test and falls behind exactly when traffic is highest — which is when
suppliers lose jobs they answered in time and stop trusting the platform.

**6. Supplier identity reaches a buyer through exactly one serialiser, which
cannot see it.** `toBuyerView()` takes a narrowed type that structurally cannot
carry `supplierId`, `businessName`, `address`, `location`, `userId` or `phone`,
so a leak is a compile error rather than a runtime discovery.

## Commands

| Command | What it does |
| --- | --- |
| `pnpm bootstrap` | Migrate and seed from empty |
| `pnpm dev` | Run the API with reload |
| `pnpm test` | Every test in the workspace |
| `pnpm typecheck` | Strict TypeScript across all packages |
| `pnpm lint` | ESLint across all packages |
| `pnpm guard` | The market-value and locale guards alone |
| `pnpm --filter @ninety/api db:reset` | Drop, migrate and reseed |
| `pnpm --filter @ninety/api db:rollback` | Revert the last migration |

## Markets

One codebase, many markets. Currency, language and text direction, vehicle
identifier, address model, payment provider, courier providers, tax treatment,
commission rate, SLA targets and business calendar are all configuration.

|  | AE — market #1 | ZA — market #2 |
| --- | --- | --- |
| Launches | Month 5 — Dubai + Sharjah together | Month 11 — Johannesburg, Cape Town, Durban |
| Text direction | Right to left | Left to right |
| Vehicle identifier | Chassis number | 17-character VIN |
| Address model | Map pin (street addressing is weak) | Street |
| Seeded live | Yes | No |

South Africa is seeded now and deliberately not live: an abstraction that is
never exercised by a second case is not an abstraction.
